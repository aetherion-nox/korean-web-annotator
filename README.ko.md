# 한국어 웹 주석 도구

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

한국어 웹 페이지에 한자어와 외래어의 원어를 표시합니다. 페이지 전체 및 선택 영역의 기본 주석 처리는 브라우저에서 실행되며, 필요하면 AI로 애매한 사전 항목을 검토할 수 있습니다. 기본 기능에는 API 키나 로컬 서버가 필요하지 않습니다.

## 1. 확장 프로그램 설치

1. [GitHub Releases](https://github.com/aetherion-nox/korean-web-annotator/releases/latest)에서 첨부된 **`Korean-Web-Annotator-v*.zip`**(전체 설치 패키지)을 다운로드하세요. GitHub에서 자동으로 제공하는 **Source code** ZIP은 사용하지 마세요.
2. ZIP 압축을 풉니다. Chrome에서 `chrome://extensions`를 열고 **개발자 모드**를 켠 다음 **압축해제된 확장 프로그램 로드**로 `manifest.json`이 있는 폴더를 선택합니다.
3. 휴대폰에서는 Quetta처럼 확장 프로그램을 불러올 수 있는 브라우저를 사용합니다.

업데이트한 뒤 확장 프로그램을 다시 로드하고 기존에 열려 있던 웹 페이지도 새로 고치세요. 일반적으로 사전을 다시 가져올 필요는 없습니다.

> **소스에서 설치:** **Code → Download ZIP**을 사용하는 경우 Python 3.10 이상을 설치하고, 압축을 푼 디렉터리에서 `python restore_distribution.py`를 실행해 저장소에 포함되지 않은 대용량 런타임을 복원해야 합니다. Release 첨부 ZIP에는 이 과정이 필요하지 않습니다.

## 2. 사전 가져오기

1. [한국어기초사전 공식 다운로드 페이지](https://krdict.korean.go.kr/download/downloadPopup)에서 **JSON 형식의 사전 ZIP**을 다운로드합니다.
2. 확장 프로그램의 **엔진 / API 설정**에서 ZIP을 선택해 가져옵니다. **사전 ZIP은 미리 압축 해제하지 마세요.**

휴대폰에서 가져오기가 느리다면 컴퓨터에서 SQLite로 변환할 수 있습니다.

```sh
python python/backend/upstream/scripts/import_dictionary.py "path/to/dictionary.zip"
```

생성된 `python/backend/upstream/hanja_dict.db`를 휴대폰으로 전송하고 같은 설정 화면에서 가져오세요.

## 3. 주석과 복사

1. 한국어 웹 페이지에서 확장 프로그램 아이콘을 클릭하고 필요에 따라 **한자어**와 **외래어** 주석을 켭니다.
2. **페이지 전체 주석**을 누르거나 텍스트를 선택한 뒤 **선택 영역 주석**, 페이지 도구 모음 또는 오른쪽 클릭 메뉴를 사용합니다.
3. **이전 주석 실행 취소** 또는 **모두 복원**으로 원래 표시로 되돌릴 수 있습니다. 도구 모음을 닫았다면 드래그할 수 있는 플로팅 버튼을 눌러 다시 열 수 있습니다.
4. **텍스트 선택 및 복사**에서 현재 본문, 본문과 주석, **원래 한국어만(기본값)**, 위쪽 주석만 중 복사 방식을 선택합니다.

텍스트를 동적으로 다시 그리는 사이트에서는 **기존 주석 복원**을 켜두세요.

## 4. 선택 기능: AI 검토

사전 기반 주석만 사용할 때는 AI가 필요하지 않습니다. 중의적 단어를 모델로 검토하려면 **엔진 / API 설정**에서 제공 업체, 모델, 엔드포인트, API 키를 설정하고 연결 테스트 및 저장 후 **선택적 모델 검토**를 켭니다.

- **일반 검토:** 로컬에서 해결하지 못한 모호성을 모델이 판별합니다. **모든 후보 모델 검토**를 켜면 요청량과 비용이 늘어날 수 있습니다.
- **선택 영역 다시 검토:** 텍스트를 선택하고 해당 버튼을 누릅니다. API 설정은 필요하지만 일반 검토 스위치는 꺼져 있어도 됩니다.
- **수동 채팅 검토:** 설정에서 켠 뒤 패널의 프롬프트를 복사하거나 다운로드하여 채팅 모델에 보냅니다. 전체 JSON 응답을 붙여넣거나 파일로 가져와 현재 배치를 검증하고 적용합니다. **API 키는 필요 없지만** 사전은 필요합니다.
- 큰 작업에서는 **배치별 컨텍스트 용량**을 조절할 수 있습니다. 완료된 배치부터 표시하려면 **완료되는 대로 주석 표시**를 켜세요.

**실험: 모델 어원 보완과 재분절:** 한자어, 외래어 원어 표기, 모델 재분절을 각각 켤 수 있으며 기본값은 모두 꺼짐입니다. 모델은 Kiwi가 잘못 나누거나 놓친 단어를 원문에서 다시 찾아 검토하지만 모델 검토와 적어도 한 가지 어원 생성 옵션이 필요합니다. 한자 한 글자는 한글 한 음절과 정확히 대응해야 하며 인명 보호는 유지됩니다. 고정 120/12개 제한 대신 설정된 컨텍스트 예산에 따라 자동 분할합니다.

**기본 검토 설정과 한 음절 보호:** 새 설치에서 모델 검토, 사전 로딩, 인명 보호, 한자어·외래어 생성, 재분절, 수동 채팅 검토가 기본 활성화됩니다. 품사 필터와 전체 후보 검토는 기본 해제입니다. 새 「한글 한 음절 로컬 주석 금지」는 기본 활성화되어 한 음절을 자동 변환하지 않고, 사전 후보는 모델 검토에 넘길 수 있습니다. 검토 결과가 없으면 한글을 유지하며 기존 저장 설정은 바꾸지 않습니다.

**v1.1.61 위험 재검토:** 「유일한 후보 위험 재검토」 및 한 음절 보호가 기본으로 켜집니다. 팀장 → team長처럼 사전에 완전하게 등재되고 확실하게 정렬되는 혼종어는 로컬에서 처리합니다. 미수록된 Kiwi 분할 복합어 및 문맥 근거가 약한 짧은 유일 후보는 변환 전에 모델에 넘기며, 겹치는 재분절 요청은 하나로 합칩니다. 확인되지 않은 결과는 한글로 유지합니다.

**v1.1.62 단어 경계 보호:** 연속 한글에서 경계가 확인되지 않은 일부 글자는 사전 항목이 있다고 해서 자동 변환하지 않습니다. 모델이 잘못된 부분 후보를 골라도 KEEP으로 안전하게 처리합니다. 재분절은 경계 위험이 확인된 곳에 집중하며 모델 한 배치는 최대 64건이고 전체 건수를 자르지 않습니다.

**v1.1.63 대형 컨텍스트 배치 수정:** 배치당64개 고정 제한을 제거했습니다. 512K/1M은 입력 및 예상 JSON 응답과 여유가 허용되면 한 번에 처리합니다. API 출력 최대 토큰(기본16384)과 수동 채팅 답변 한도(기본65536)는 컨텍스트와 별도로 설정하며 실제 모델 한도를 확인해야 합니다.

**v1.1.64 미수록 복합어 복원:** 실험적 재분절 및 어원 생성 옵션을 켜면 전체 표제어나 구성 요소가 사전에 없어도 명사 복합어와 미수록 명사 표현을 하나의 검토 대상으로 보낼 수 있습니다. 확인된 부분 어원과 모델의 높은 확신을 바탕으로 실제 원어 표기를 제안하며 특정 기관 이름을 규칙에 고정하지 않습니다. 보호된 인명은 제외하고 모든 위치와 글자 수를 검증합니다.

**v1.1.65 부분 수정:** GEN_SEGMENTS의 형태가 대상 원문에 한 번만 나타날 때 잘못된 start/end를 자동으로 고칩니다. 단독 한 음절은 실제 사전 항목과 Kiwi의 명사·조사 경계가 함께 필요합니다. 수동 검토에서 일부 결과만 잘못되면 유효한 답변은 보존하고 잘못된 target_id만 다시 제출할 수 있습니다. batch_id는 그대로 유지합니다.

**v1.1.66 수동 검토 통합 검증:** 백그라운드와 페이지 오프라인 복구에 동일한 검증기를 사용합니다. 잘못된 항목의 target_id와 이유를 알려 주며, 통과한 답변을 유지하고 실패한 ID만 원래 batch_id로 다시 제출할 수 있습니다. 원문과 같은 무효 변환 부분은 안전하게 버리고, 사전·관형 수식 또는 조사 근거가 있는 한 음절 명사는 허용합니다. 메뉴 링크의 단어 경계도 보존합니다.

API 검토 시 관련 웹 페이지 텍스트와 사전 후보가 설정한 모델 서비스로 전송됩니다. 개인정보 보호와 API 요금에 주의하세요.

**v1.1.67 혼합 오류 복구:** 자동·수동 검토에서 다른 배치의 ID가 섞여도 정상 답변은 유지합니다. 중복 target_id는 해당 대상만 무효화하며, 부분 수정 프롬프트의 JSON 예시는 고정된 t0 대신 실제 남은 ID를 사용합니다. batch_id 불일치는 계속 전체 거부합니다.

**v1.1.68 수동 검토 즉시 미리보기:** 모델 생성 어원은 replacement 또는 segments만 제출하면 되고 confidence/evidence는 필수가 아닙니다. 사전 선택은 해당 대상에 허용된 choice_id만 사용할 수 있습니다. 검증된 답변은 나머지 ID를 수정하는 동안 되돌릴 수 있는 미리보기로 표시됩니다. 변환 여부와 DOM 원문 변경도 진단하며, 미리보기는 최종 확정이 아닙니다.

**v1.1.69 유일 후보의 의미 검토:** 사전 후보가 단 하나인 2음절 어휘는 높은 로컬 점수만으로 의미가 맞는다고 간주하지 않습니다. 명확한 연어·수량 단위 근거가 없다면 모델에 해당 문맥의 정의를 다시 검토하도록 보냅니다. 단순 동음이의어를 잘못 표기하지 않도록 하되, 다수의 사전 항목이나 확실한 연어가 있는 어휘의 기존 빠른 경로는 유지합니다.

**v1.1.70 전체 어휘 단위 우선 검토:** 실험적 한자 표기는 먼저 어휘의 전체 어간과 조사·고유어 경계를 확인합니다. 근거 없는 한 음절 변환은 계속 거부하지만, API 재시도 및 수동 복구에서 해당 대상의 오류 이유를 알려 전체 단어를 다시 판단하게 합니다. 누락된 한자를 임의로 채우지 않으며 불확실하면 KEEP을 사용합니다. 출력 예산에서 삭제된 confidence/evidence 필드를 제외했습니다.

## 5. 문제 해결

- **주석이 시작되지 않음:** 사전 가져오기 여부를 확인하고 확장 프로그램 및 웹 페이지를 새로 고치세요.
- **업데이트 후에도 예전 오류가 발생함:** `chrome://extensions`에서 확장 프로그램을 다시 로드한 다음 열려 있던 탭도 새로 고치세요.
- **수동 검토 배치가 남아 있음:** 탭을 열린 상태로 두고 각 배치의 JSON을 제출·검증하세요. 완료 전에 페이지를 새로 고치지 마세요.
