# 한국어 웹 주석 도구 3.3.5

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · **한국어**

한국어 웹 페이지에 사전에 근거한 한자와 외래어의 원어를 표시하는 확장 프로그램입니다. 사전과 분석 엔진은 확장 프로그램 안에서 실행되므로 Python 서버가 필요하지 않습니다. 선택적 모델 검토는 사용자가 설정한 API를 사용합니다.

## 설치

설치 ZIP을 풀거나 이 저장소를 다운로드하세요. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고, 압축 해제된 확장 프로그램 로드 기능으로 `manifest.json`이 있는 폴더를 선택합니다. Quetta에서는 확장 프로그램 로드 기능을 사용하세요. 업데이트 후 확장 프로그램을 다시 로드하고 열려 있는 웹 페이지도 새로 고칩니다.

엔진 / API 설정에서 공식 한국어기초사전 JSON ZIP 또는 `hanja_dict.db`를 가져옵니다. 공식 다운로드: <https://krdict.korean.go.kr/download/downloadPopup>. 사전 데이터, 개인 설정, API 인증 정보는 배포 파일에 포함하지 않습니다.

## 컴퓨터에서 사전 DB 만들기

Python 3.10 이상에서 저장소 최상위 폴더를 기준으로 실행합니다. 추가 패키지는 필요하지 않습니다.

```sh
python python/backend/upstream/scripts/import_dictionary.py "path/to/dictionary.zip"
```

결과는 `python/backend/upstream/hanja_dict.db`입니다. 확장 프로그램으로 가져오거나 휴대폰으로 옮겨 Quetta에서 가져올 수 있습니다. 출력 위치는 환경 변수 `HANJA_DB_PATH`로 지정할 수 있습니다. 가져오기 도구는 항목·뜻풀이·용례 개수, 외래 키, 사전 날짜 및 SQLite 무결성을 확인한 후 DB를 교체하며, 기존 DB는 백업합니다. 읽을 수 있는 Python 소스는 `python/`에 있고, 브라우저가 불러오는 내장 소스는 `runtime/python-sources.json`에 있습니다.

## 사용

팝업, 도구 모음 또는 오른쪽 클릭 메뉴에서 전체 페이지 주석을 시작합니다. 분석을 마친 후 표준 `ruby`/`rt` 요소를 한 번에 삽입하며 브라우저가 배치합니다. 선택 영역 재주석, 모델 재검토, 실행 취소, 진단 및 복원을 지원합니다.

복사는 표시된 본문만, 본문과 주석(`본문(주석)`), 원래 한국어만(기본값), 위쪽 주석만의 네 가지 방식입니다. 이 확장 프로그램의 주석을 포함하지 않는 선택 영역은 브라우저의 일반 복사 동작을 유지합니다.

선택한 텍스트가 없으면 일부 주석이 이미 있어도 전체 페이지를 처리할 수 있습니다. 주석 없는 한국어를 선택하면 선택 영역을 처리하고, 주석된 텍스트를 선택하면 마지막 주석 작업을 취소할 수 있습니다. 기본적으로 전체 페이지 처리 후 자동 처리를 멈춥니다. 이 설정을 끄면 새 텍스트를 처리하지만 페이지 자체 수정으로 사라진 주석을 복원하지는 않습니다.

3.3.5에서는 팝업이 시작 요청을 즉시 백그라운드에 전달합니다. 팝업을 닫아도 전달 작업은 계속되며 시작 중 반복 클릭은 하나로 합쳐집니다.

## 검증 및 참고

검증 코드와 이전 로그가 포함되어 있습니다. 모바일 화면 테스트는 확장 API와 분석 결과를 모의한 테스트이며 Quetta 실제 기기 테스트는 아닙니다. 이전 테스트 스크립트에는 당시 작업 환경의 경로가 포함되어 있습니다. 표준 ruby 삽입과 주석 선택 방식은 Furiganator 1.2.0을 참고했습니다. Kiwi와 Pyodide 등의 라이선스는 각 원 프로젝트의 조건을 따릅니다. 자세한 내용은 [English](README.en.md)를 참고하세요.

## GitHub 다운로드

업로드 크기 제한 때문에 큰 런타임 파일과 원래 설치 ZIP을 분할 저장합니다. 저장소 전체를 다운로드한 뒤 확장 프로그램을 로드하기 전에 `python restore_distribution.py`를 실행하세요. SHA-256을 확인하고 파일을 복원합니다. 원래 ZIP은 `distribution/Korean-Web-Annotator-v3.3.5-Extension.zip`에 복원됩니다. 기존 설치 ZIP에는 이 단계가 필요하지 않습니다.
