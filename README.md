# 韩语网页标注器 3.3.5

保留 3.3.0 已验证的原生 ruby/rt 标注方式，恢复工具条和插件页的原有操作及设置。韩语词典、本地引擎、可选模型审核和 API 配置继续沿用。

## 标注与操作

分析期间不改动正文，全部完成后一次性插入原生 ruby/rt，由浏览器排版。不添加段落外壳，不进行滚动布局测量或重绘恢复。

工具条保留整页标注、选区重标、模型重审选区、撤销、诊断、还原和关闭，不提供复制按钮。关闭工具条后，后续进度不会将其重新打开。

“选择与复制文字时”独立框提供四种模式：
- 只复制当前显示的正文。
- 复制正文和标注，纯文本格式为 正文(标注)。
- 只复制原韩语（谚文），默认；汉字词可选择上方谚文，外来语选择正文韩语。
- 只复制上方标注。

复制包含本插件标注的选区时按所选模式生成剪贴板文本；不改变页面 ruby 排版。不涉及本插件标注的选区保持浏览器行为。

右键菜单：未选中文字时始终提供整页标注，即使页面已有部分标注；选择未标注韩语时提供选区标注；选中已标注文字时提供撤销上次标注。操作发送至实际点击的页面框架。

插件页保留标注类型、忽略缓存、完成后停止自动标注、退出时清理缓存、工具条开关、显示方式、仅有韩语时显示和界面语言等设置。默认整页完成后停止自动处理；取消该设置后只处理新增文本，不恢复网页重写后丢失的旧标注。

## 安装与升级

解压 ZIP，在扩展管理页加载 manifest.json 所在目录。Quetta 使用其扩展加载功能。升级后重新加载插件，并刷新已打开的网页，让新版脚本和样式生效。

首次使用在“引擎 / API 设置”导入词典。词典、设置及 API 凭据不随升级包分发；升级继续使用已有浏览器本地配置。

## 在电脑上把词典转为 DB

转换代码位于 `python/backend/upstream/scripts/import_dictionary.py`，从插件内嵌源码原样提取，配套数据库结构代码也已包含。使用 Python 3.10 或以上，无需安装第三方包。在仓库根目录运行：

```sh
python python/backend/upstream/scripts/import_dictionary.py "你的词典.zip"
```

生成 `python/backend/upstream/hanja_dict.db`，在插件设置页直接导入；手机可先从电脑传入 DB，省去手机解析 ZIP 和建库的时间。可通过环境变量 `HANJA_DB_PATH` 指定输出路径。转换器检查数据计数、外键、词典快照日期和数据库完整性，成功后替换目标文件，并备份已有数据库。词典下载：<https://krdict.korean.go.kr/download/downloadPopup>。

可读 Python 源码在 `python/`，浏览器实际加载对应的 `runtime/python-sources.json`。
