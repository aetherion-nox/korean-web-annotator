# 韩语网页标注器

**简体中文** · [繁體中文](README.zh-TW.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

在韩语网页中显示汉字词和外来语的词源，帮助阅读时理解词汇。当前正式版为 **1.1.11**。扩展使用浏览器内的分词器和词典进行分析，也可结合大模型处理有歧义的词语或补充词源。

## 功能

- 在网页中显示汉字词、外来语原词，可分别控制两种标注。
- 支持整页和选区标注，也可通过网页工具条或右键菜单操作。
- 使用 Kiwi 分词和本地词典分析；词典导入后，基础标注可在浏览器内完成。
- 支持动态网页的标注恢复、可访问的 iframe、撤销与重做，以及多种文字复制方式。
- 整页标注完成时汇总各参与框架的实际 DOM 标注；未收到的框架回执单独提示，诊断保留各框架明细。
- 默认在正常标注完成后自动收起网页工具条，可在插件设置中关闭；即使禁用悬浮球也会自动收起；可以按显示设置重新选中文字，或点击已启用的悬浮球重新打开。
- 本地分析与模型审核分别保留最近使用的最多 1000 条记录；退出时清除缓存默认关闭，可跨浏览器会话复用，手动清除不会被正在运行的旧任务重新填充。
- 本地分析按段落复用；API 审核缓存按原文、前后段落和当前候选及设置匹配，复用前重新校验词源和分词修复。变化处重新审核，手动模式与强制重新分析不读取模型审核缓存。
- 提供可选的大模型审核：既可配置 API 自动审核，也可通过聊天界面手动提交结果。
- 提供实验性的词源补充与智能分词修复；没有词典时，也可结合相应实验选项使用模型审核。

词典、分词和模型判断都可能有误。人名、专有名词及缺少上下文的词语尤其需要结合原文核对。

## 安装

1. 在 [Releases](https://github.com/aetherion-nox/korean-web-annotator/releases/latest) 下载插件安装包 `Korean-Web-Annotator-v*.zip`，并解压。
2. 在 Chrome 打开 `chrome://extensions`，开启**开发者模式**。
3. 点击**加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。
4. 刷新要标注的网页。支持加载扩展的其他浏览器可参考其扩展安装方式。

扩展需要访问 HTTP/HTTPS 网页，以读取待标注文字并显示结果。浏览器内部页面、扩展管理页和 Chrome 商店等受保护页面不能注入脚本。

从源码安装需要 Python 3.10 或以上版本：在源码目录运行 `python restore_distribution.py`，恢复运行时文件后再加载扩展。Release 中的插件安装包已包含运行时。

## 导入词典

可以使用以下任一方式：

1. **预制词典：** 从 [Releases](https://github.com/aetherion-nox/korean-web-annotator/releases/latest) 下载 `hanja_dict.zip`，解压得到 `hanja_dict.db`。在扩展的**引擎 / API 设置**中选择 DB 文件并导入。
2. **官方词典：** 从[韩国国立国语院韩国语基础词典下载页](https://krdict.korean.go.kr/download/downloadPopup)下载 JSON 格式词典 ZIP，在同一设置页选择 ZIP 并导入，无需解压。

预制词典根据韩国国立国语院《韩国语基础词典》制作，属于非官方发行。文本数据采用 [CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/)；来源为[韩国语基础词典](https://krdict.korean.go.kr/)。图片及音频链接不因此获得相同许可。

## 使用

打开韩语网页并点击扩展图标，按需启用**汉字词**或**外来语**，然后选择**一键标注整页**。也可以先选中文字，再使用选区标注、网页工具条或右键菜单。

工具条支持撤销和重做；隐藏后可通过悬浮球重新打开。动态页面重绘时，可开启**动态网页兼容：恢复已有标注**。文字复制内容可在扩展设置中选择。

## 大模型审核

在**引擎 / API 设置**中选择服务商和模型、填写 API Key，测试连接并保存，然后启用模型审核。可以按服务商设置思考模式、输出 Token 限额和批次容量；也可以自行填写兼容接口的 URL 与模型 ID。

各服务商不一定支持同一套思考控制、流式输出和 JSON 协议；插件会根据内置适配器处理差异，实际使用请先测试连接。

- **普通审核：** 模型结合上下文判断词典候选；可按需扩大审核范围。
- **重审选区：** 对选中的文字单独请求模型重新判断。
- **手动聊天审核：** 复制或下载提示词，发送给聊天模型，再将返回的 JSON 粘贴或导入审核面板，无需 API Key。
- **实验性功能：** 可开启模型补充汉字或拉丁字词源，以及智能分词修复。无词典时需启用模型审核和对应的实验性词源补充选项。

每批上下文容量可在设置中调整，默认档位为 1M；实际可用容量和输出上限取决于所选模型。需要逐批查看结果时，可开启**边完成边标注**。

使用 API 审核时，待处理的网页文字及候选信息会发送给所配置的模型服务商；请求量和费用取决于具体服务。手动聊天审核需由使用者自行将提示词发送给所选聊天服务。

## 常见问题

- **没有标注：** 检查词典是否导入、对应标注模式是否开启，以及浏览器是否允许扩展访问当前网站。无词典模式还需开启模型审核和对应实验选项。
- **网页显示异常：** 在扩展管理页重新加载扩展，并刷新网页后重试。
- **手动审核未完成：** 保持网页打开，按面板提示逐批提交或修正 JSON 答案。
