为韩语网页标注汉字词和外来语原词，帮助阅读韩语。导入词典后即可在浏览器内使用，无需启动本地服务器；也可自行配置 API，启用大模型审核。

## 安装

1. 解压本次提供的完整安装包 `Korean-Web-Annotator-v1.1.11.zip`。
2. 解压 ZIP。安装包包含完整运行时，无需安装 Python，也无需运行还原脚本。
3. Chrome 打开 `chrome://extensions`，开启“开发者模式”，点击“加载已解压的扩展程序”，选择 `manifest.json` 所在文件夹。手机 Quetta 使用其扩展加载功能。

更新后重新加载插件，并刷新已打开的网页。

若下载的是 **Code → Download ZIP** 源码包，则需 Python 3.10 或以上，在解压后的文件夹中先运行 `python restore_distribution.py`，再加载插件。

## 导入词典

从[韩国语基础词典官网](https://krdict.korean.go.kr/download/downloadPopup)下载 JSON 格式的词典 ZIP，在插件的“引擎 / API 设置”中导入，无需先解压。词典需自行下载。

手机导入较慢时，可先在电脑上转换为 DB：

```sh
python python/backend/upstream/scripts/import_dictionary.py "你的词典.zip"
```

将生成的 `python/backend/upstream/hanja_dict.db` 传到手机，再在同一设置页导入。

## 使用

- 打开韩语网页，点击插件里的“标注整页”，或通过工具条、右键菜单开始标注。
- 选中文字可进行选区标注或重新标注；需要恢复时使用“撤销”或“还原”。
- 在“选择与复制文字时”选择复制方式：当前正文、正文和标注、原韩语（默认），或上方标注。
- API 服务商支持 OpenAI 和 Claude；模型列表包含截至 2026-10-12 官方文档中的最新系列。思考开关和强度按模型能力显示，不能关闭思考的模型仅显示强度。
- **手动聊天审核**：在设置页开启后，网页面板会显示完整任务提示词，可复制或下载 TXT，发给你选择的聊天模型，再把其完整 JSON 答案粘贴回面板。无需 API Key；仍需词典。较大任务按批处理；开启“边完成边标注”即可逐批显示。刷新或离开网页会取消尚未完成的任务。
- **审核**：普通标注时，让大模型处理本地算法未能解决的歧义。需要配置服务商、模型和 API Key，并开启审核。
- **模型重标（模型重审选区）**：选中文字后，主动交给大模型重新判断。同样需要配置大模型 API，但无需开启“审核”。
- 只使用本地算法标注时，无需大模型 API。

## 1.1.31：姓名范围与数量结构修复

- 完整搭配验证：仅当原词典短语按原顺序、完整成分和目标位置匹配原文时，才加0.25分。长术语中的任意两个词共现不再构成证据；保留有分词依据的末尾格助词。
- 数字紧邻或仅隔空格的目标词，只有词典释义明确提供计量用法时才额外加0.05分，最多一次。NNB标签本身和缺失元数据不产生该加分；仅语法/数量优势不能确定有竞争的转换。最低分0.50和领先分差0.15不变。
- 审核同时提供目标附近词素和数量邻接信息；手动/API共用同一提示与字段。
- 疑似姓名采用完整范围保护：结合拆分的NNP前缀或词典明确的姓氏释义、格／补助等助词和连续名词结构；已有完整词典词条作为反证。内部普通词义不再替换该范围，同一输入中的重复裸姓名也保留。兼容姓名后主格“이”被误标为冠形词的情况。没有姓氏/分词证据的姓名仍可能漏识别，不从读音猜测姓名汉字。
- 词典格式及数据库无需迁移。缺失/未识别的词性和释义保持未知。合法单字词、外来语、混种词以及nonconversion/KEEP设计保留。

验证与限制：使用插件自带Kiwi 0.23.2生成分词样本，并对真实SQLite查询、评分、转换和两个插件的完整分析路径进行回归检查：每个插件20项Python回归、5项审核字段检查，并检查实际打包的Pyodide＋Kiwi运行结果；未调用真实LLM。原Web npm test引用的旧tests文件未随历史发布包提供，无法运行该完整套件。

安装后重新加载插件并刷新页面；引擎版本已更新，旧本地分析缓存不会复用。


## 1.1.32：Kiwi 独立更新

设置页新增“Kiwi 引擎更新”：显示当前引擎/模型版本及内置或独立更新来源；检查官方 kiwi-nlp 稳定版及对应 Kiwi 模型，下载并校验后进行实际分词检查，通过后才切换。当前已用上游0.24.1引擎与同版模型验证。

- 引擎JS/WASM来自官方npm包，校验SHA-512；模型来自同版本官方GitHub Release，校验发布的SHA-256。缺失、不兼容或损坏时不替换当前引擎。
- 下载代码仅在独立沙箱的worker中运行，未向它传递词典数据库、设置或API Key；分词结果交给原有词源算法。下载后保存本机，可离线重启使用；支持恢复内置0.23.2引擎。
- 切换不删除词源词典或用户设置；引擎/模型校验值纳入分析缓存标识。标注/API或手动审核任务持有任务锁，完成或取消后才允许切换；坏的缓存引擎在任务开始前先回退内置版。
- 兼容新模型将姓名首音节识别为数词的情况；词典明确的单位用法作为反证，避免把数量短语保护成姓名。
- 进度由离屏页面通过后台转发，支持五种界面语言。首次检查/下载时请求访问官方更新源的权限。大模型接口密钥不用于Kiwi更新。

验证：17项更新/管理/设置/worker自动检查；实际0.24.1 JS/WASM与模型运行、沙箱模块图和浏览器式worker加载、IndexedDB保存/离线重启/恢复/词典保留；原姓名/单位回归各22项继续通过。当前环境禁止访问浏览器内部插件页，未完成真实Chromium沙箱CSP与界面验证；已保留检查脚本。旧Web完整npm测试引用的历史tests文件缺失，无法运行该套件。
