# 韓国語ウェブ注釈ツール 3.3.5

[简体中文](README.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

韓国語のウェブページに、辞書に基づく漢字や外来語の原語を表示する拡張機能です。辞書と解析エンジンは拡張機能内で動作し、Python サーバーは不要です。任意のモデル審査では、設定した API を使用します。

## インストール

インストール ZIP を展開するか、このリポジトリをダウンロードします。Chrome の `chrome://extensions` でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」から `manifest.json` があるフォルダーを選択します。Quetta では拡張機能の読み込み機能を利用してください。更新後は拡張機能を再読み込みし、開いているページも更新します。

「エンジン / API 設定」で、公式の韓国語基礎辞典 JSON ZIP または `hanja_dict.db` を取り込みます。公式ダウンロード：<https://krdict.korean.go.kr/download/downloadPopup>。辞書データ、個人設定、API 認証情報は配布物に含まれません。

## パソコンで辞書 DB を作成

Python 3.10 以降を使用し、リポジトリのルートから実行します。追加パッケージは不要です。

```sh
python python/backend/upstream/scripts/import_dictionary.py "path/to/dictionary.zip"
```

出力先は `python/backend/upstream/hanja_dict.db` です。拡張機能に取り込むか、スマートフォンに転送して Quetta に取り込めます。別の出力先は環境変数 `HANJA_DB_PATH` で指定します。取り込み処理は件数、外部キー、辞書の日付、SQLite の整合性を検証し、成功後に置き換えます。既存の DB はバックアップします。読みやすい Python ソースは `python/`、ブラウザー用の埋め込みソースは `runtime/python-sources.json` にあります。

## 操作

ポップアップ、ツールバー、右クリックメニューからページ全体を注釈できます。解析が完了した後、標準の `ruby`/`rt` を一括挿入し、ブラウザーが配置します。選択範囲の再注釈、モデル再審査、取り消し、診断、復元にも対応します。

コピーは「表示中の本文のみ」「本文と注釈（本文(注釈)）」「元の韓国語のみ（既定）」「注釈のみ」の四種類です。注釈を含まない選択範囲は通常のブラウザー動作を維持します。

未選択なら一部が注釈済みでもページ全体を処理できます。未注釈の韓国語を選択すると範囲注釈、注釈済みの文字を選択すると直前の注釈を取り消せます。既定ではページ処理後に自動処理を停止します。停止設定を解除すると新規テキストを処理しますが、ページ書き換えで消えた注釈は復元しません。

3.3.5 ではポップアップから起動要求を直ちにバックグラウンドへ送信します。ポップアップを閉じても引き継ぎは継続し、起動中の重複クリックはまとめられます。

## 検証と参考

同梱の検証コードと過去のログを参照してください。モバイル画面のテストは API と解析結果を模擬したもので、Quetta 実機の検証ではありません。過去のスクリプトには当時の環境パスが含まれます。標準 ruby の挿入と注釈選択方式は Furiganator 1.2.0 を参考にしています。Kiwi、Pyodide などのライセンスは各上流の条件に従います。詳細は [English](README.en.md) も参照してください。

## GitHub からのダウンロード

アップロード制限のため、大きな実行時ファイルと元のインストール ZIP は分割して保存しています。リポジトリ全体をダウンロードし、拡張機能を読み込む前に `python restore_distribution.py` を実行してください。SHA-256 を検証して復元します。元の ZIP は `distribution/Korean-Web-Annotator-v3.3.5-Extension.zip` に復元されます。既存のインストール ZIP にはこの操作は不要です。
