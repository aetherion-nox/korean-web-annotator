# 韓国語ウェブ注釈ツール

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · **日本語** · [한국어](README.ko.md)

韓国語のウェブページに漢字や外来語の原語を表示します。ページ全体や選択範囲の注釈はブラウザー内で実行でき、必要に応じて AI による語義の確認も利用できます。基本機能に API キーやローカルサーバーは不要です。

## 1. 拡張機能をインストール

1. [GitHub Releases](https://github.com/aetherion-nox/korean-web-annotator/releases/latest) から、添付ファイルの **`Korean-Web-Annotator-v*.zip`**（完全版）をダウンロードします。GitHub が自動生成する **Source code** ZIP は使用しないでください。
2. ZIP を展開します。Chrome で `chrome://extensions` を開き、**デベロッパーモード**を有効にして、**パッケージ化されていない拡張機能を読み込む**から `manifest.json` のあるフォルダーを選択します。
3. スマートフォンでは、Quetta など拡張機能の読み込みに対応したブラウザーを使用します。

更新後は拡張機能を再読み込みし、開いているウェブページも更新してください。通常、辞書の再取り込みは不要です。

> **ソースからのインストール：** **Code → Download ZIP** を使う場合は Python 3.10 以降を用意し、展開先で `python restore_distribution.py` を実行して、リポジトリに含まれない大容量ランタイムを復元します。Release の添付 ZIP では不要です。

## 2. 辞書を取り込む

1. [韓国語基礎辞典の公式ダウンロードページ](https://krdict.korean.go.kr/download/downloadPopup)から **JSON 形式の辞書 ZIP** を入手します。
2. 拡張機能の **エンジン / API 設定**で ZIP を選択して取り込みます。**辞書 ZIP の解凍は不要です。**

スマートフォンでの取り込みが遅い場合は、パソコンで SQLite に変換できます。

```sh
python python/backend/upstream/scripts/import_dictionary.py "path/to/dictionary.zip"
```

生成された `python/backend/upstream/hanja_dict.db` をスマートフォンに移し、同じ設定画面から取り込みます。

## 3. 注釈とコピー

1. 韓国語のページを開いて拡張機能のアイコンをクリックし、必要に応じて**漢字語**と**外来語**の注釈を有効にします。
2. **ページ全体を注釈**を押すか、テキストを選択して**選択範囲を注釈**、ページ内ツールバー、右クリックメニューを使用します。
3. **前回の注釈を取り消す**または**すべて元に戻す**で表示を復元できます。ツールバーを閉じた場合は、移動可能なフローティングボタンから再表示できます。
4. **テキスト選択・コピー**の設定で、表示中の本文、本文＋注釈、**元の韓国語のみ（初期設定）**、上部の注釈のみを選べます。

文字が動的に再描画されるサイトでは、**既存の注釈を復元**を有効にしておいてください。

## 4. 任意：AI による語義確認

辞書による注釈だけなら AI は不要です。曖昧な語義をモデルに確認させる場合は **エンジン / API 設定**でサービス、モデル、エンドポイント、API キーを設定し、接続テストと保存を行ってから**モデル審査**を有効にします。

- **通常の審査：** ローカル処理では解決できない語義をモデルで判別します。**全候補をモデル審査**にするとリクエスト数や費用が増える場合があります。
- **選択範囲の再審査：** テキストを選択して該当ボタンを押します。API の設定は必要ですが、通常の審査スイッチはオフでも使えます。
- **手動チャット審査：** 設定で有効にし、パネルのプロンプトをコピーまたはダウンロードしてチャットモデルへ送信します。返された完全な JSON を貼り付けるかファイルから読み込み、現在のバッチを検証して適用します。**API キーは不要**ですが辞書は必要です。
- 大きなタスクでは**バッチごとのコンテキスト容量**を調整できます。完了したバッチから表示したい場合は**順次注釈**を有効にしてください。

**実験：語源補完とモデル再分割：** 漢字語、外来語の原綴り、再分割の3つのスイッチは初期状態で無効です。モデルは Kiwi の誤分割や見落としを原文から再判定できますが、モデル審査と少なくとも1つの語源補完スイッチが必要です。漢字は韓国語1音節につき1字を厳守し、人名保護は維持されます。処理件数を固定値で切り捨てず、選択したコンテキスト容量に応じて分割します。

**初期設定と１音節の保護：** 新規インストールではモデル審査、事前読込、姓名保護、漢字語・外来語の補完、再分割、手動チャット審査を有効にします。品詞フィルターと全候補審査は無効です。新しい「１音節語のローカル変換禁止」は有効で、単一ハングル音節の自動変換を防ぎ、辞書候補のモデル審査は許可します。有効な回答がない場合は原文を維持し、保存済み設定は変更しません。

**v1.1.61 リスク再審査：** 「唯一候補のリスク再審査」と１音節語保護は初期状態で有効です。辞書に完全な見出し語があり、正確に対応する混種語（팀장 → team長）はローカル変換できます。未収録で Kiwi が細分化した複合語や文脈根拠の弱い短い単一候補はモデル再審査に回し、重複する再分割要求をまとめます。不明な場合はハングルを保持します。

**v1.1.62 語境・語境界の安全性：** 未確認の語境界を持つハングル連続文字列の一部を、辞書の一致だけで自動変換しません。モデルが不適切な部分候補を選んでも KEEP に降格します。再分割は語境界の疑いがある箇所に絞り、64件ごとにモデルへ送ります（全文の件数制限はありません）。

**v1.1.63 大規模コンテキストの分割修正：** 1バッチ64件の固定上限を廃止しました。512K／1Mは入力・予測JSON回答・余裕が収まる限り一括審査します。API出力上限（初期値16384）と手動チャットの出力上限（初期値65536）はコンテキスト容量と別々に設定し、実際のモデル制限に合わせてください。

**v1.1.64 辞書未収録語の復元：** 実験的なモデル再分割・語源補完を有効にすると、辞書に完全形や構成要素がなくても名詞複合語を一つの対象として審査できます。辞書で確認できる部分とモデルの確実な語源知識を組み合わせます。固有名詞の特定例に依存せず、確定された人名保護と出典・文字数・位置の検証は維持します。

**v1.1.65 部分修正：** GEN_SEGMENTS の部分語が元の対象内に一意に存在するときだけ start/end を修正します。独立した1音節には辞書の一致と Kiwi の名詞・助詞境界が必要です。手動審査の一部が無効でも正常な回答を保持し、無効な target_id のみを再提出できます。同じ batch_id を使用してください。

**v1.1.66 手動審査の統一検証：** バックグラウンドとオフライン復元が同じ検証器を使用します。無効な行だけ target_id と理由を表示し、正常な行は保存して差分のみ再提出できます。置換前後が同一の部分は安全に省略し、辞書と連体修飾・助詞の証拠がある1音節語は許可します。ナビゲーションのリンク間には分析上の境界を維持します。

API 審査では対象のウェブページのテキストと辞書候補が設定したサービスに送信されます。プライバシーと料金に注意してください。

**v1.1.67 混在する不正 ID の修正：** 自動・手動審査で別バッチの ID が混ざっても、他の正しい回答は保持します。重複 ID はその対象のみ無効とし、再提出用の JSON 例には未解決の実際の target_id を使います。batch_id が異なる場合は引き続き全体を拒否します。

**v1.1.68 手動審査の即時プレビュー：** 生成語源の confidence と evidence は不要になり、replacement または segments のみを返します。辞書選択は対象に許可された choice_id のみ有効です。正しい回答は残りの ID の修復中にも取り消し可能なプレビューとして表示し、変換・KEEP・DOM 位置の失効を診断します。プレビューは最終確定ではありません。

**v1.1.69 唯一候補の意味チェック：** 辞書候補が一件だけで、確実な共起・単位の根拠がない二音節語は、内部スコアが高くても自動置換せずモデルに意味を確認します。辞書にない現在の意味に対して、同音の別義を誤って流用しないための一般的な対策です。辞書項目が複数ある場合や十分な共起根拠がある場合は従来の高速処理を維持します。

## 5. 問題が起きた場合

- **注釈が始まらない：** 辞書の取り込みを確認し、拡張機能の再読み込みとページの更新を行ってください。
- **更新前のエラーが出続ける：** `chrome://extensions` で再読み込みしてから、開いていたタブを更新してください。
- **手動審査が途中で止まった：** タブを開いたまま、各バッチの JSON を順に提出・検証してください。完了前にページを更新しないでください。
